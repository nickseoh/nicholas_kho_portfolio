# Nicholas Kho — Portfolio

A single-page portfolio built with plain HTML and CSS. No frameworks, no build step, no images.

## Sections
- About
- Projects: YourOwn (in progress), Axis (completed)
- Contact

## Run locally
Open `index.html` in a browser.

## Deploy with GitHub Pages
1. Push this repo to GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/ (root)`.
4. Save. The site goes live at `https://<username>.github.io/<repo-name>/` after a minute or two.
